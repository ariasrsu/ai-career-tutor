# 本地知识库操作规则

本 Skill 不附带教材、数据库或检索程序。先确认使用者的资料目录、来源清单和可用检索工具；没有这些配置时，可根据本轮提供的摘录教学，不声称拥有教材库。

## 检索与引用

- 区分计划收集、本地已有、已索引可检索、已人工核验四种状态。
- 检索结果只是候选证据。读取原件上下文，确认支持结论后，引用文件名和章节、行号或 PDF 页序；文件页序可能不同于书内页码。
- 网页课堂若提供来源 ID 和短摘录，应检查关联性；没有命中不能声称查过所有教材。

## 管理与更新

- 新增教材核对标题、版本、来源、许可、可提取性，登记实际路径和使用范围。
- 使用实际可用的索引工具更新后，检查覆盖情况，并以主题问题抽检；不假设特定命令或数据库存在。
- 用户临时笔记与正式教材分别管理；笔记不自动成为权威依据。
- 不公开私人资料、商业教材原文、索引数据库、聊天记录或个人学习档案。使用短摘录和自己的解释。
- 录屏、图片和代码附件没有可核验文本时，不称为已检索教材。提取失败、缺页或索引过期时标记限制。
