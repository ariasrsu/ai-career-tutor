# AI 转行导师

配套网页：**AI 学习工作台**。

一步一步，把 AI 知识学成自己的能力。

AI 转行导师是一套可在本地运行的中文 AI 学习工具，包含黑板网页工作台和 `ai-career-tutor` 导师 Skill。你可以读课程、做练习、记笔记，再和 AI 导师讨论、复练与模拟面试。

## 包含什么

- **黑板课堂**：8 周、6 个模块、24 节原创课程，当前主线为 AIGC 产品经理，以营销素材生成工作台为贯穿案例。
- **课程学习**：板书、讲课笔记、工作产物、理解练习、迁移问题与建议阅读。
- **学习记录**：浏览器保存个人进度和笔记，支持学习数据导出。
- **AI 导师**：讲解、逐题批改、学习路线和模拟面试；Skill 也可独立使用，覆盖 AI 产品、运营与应用开发方向。网页课程目前主要面向 AIGC 产品经理。
- **个人资料**：导入自己的 MD/TXT 笔记，按提问匹配相关摘录。公开版不附带私人教材库。

## 启动网页

需要 Node.js 18 或更高版本及 npm。在仓库目录执行：

```bash
cd classroom
npm install
npm run dev
```

打开 http://127.0.0.1:3000 。默认只监听本机，可用 `PORT` 环境变量修改端口。

课程阅读不需要连接模型。实时问答使用 Codex SDK，需本机已有可用的 Codex 登录与网络；点击连接并得到真实回复后才确认可用。模型调用可能消耗账号额度。未连接或调用失败时，页面不会用预写答案冒充实时回复。

## 教材与隐私

上传笔记存放在 `classroom/materials/`，默认不进入 Git。服务会将与问题相关的笔记摘录、提问和课程状态发送给模型；请只导入你允许这样使用的资料。学习进度保存在当前浏览器，模型会话由本地服务管理；重启不会保证恢复会话。

课堂包不包含教材原文件、私人索引数据库、个人笔记、截图或登录信息。字体使用系统回退字体，没有打包原项目的字体文件。

内置笔记检索无需额外索引。若自行接入正式教材库，可用 `KNOWLEDGE_INDEX_SCRIPT` 指向自己的 Python 索引程序；程序需支持 `status`、`search`、`files` 并输出 JSON。公开版未提供该外部程序，不配置时资料库为空，仍可阅读课程与上传笔记。建议阅读书目不代表已经取得或索引对应教材。

## 独立使用 Skill

将根目录 `SKILL.md` 和 `references/` 一起放入助手支持的 Skill 目录，例如命名为 `ai-career-tutor`。调用示例：

```text
使用 $ai-career-tutor，教我理解 RAG，出一道题后等我回答，再批改。
```

`classroom/.agents/skills/ai-career-tutor/` 是网页服务加载的同一份规则；根目录保留独立安装入口。

## 目录

- `classroom/黑板工作台.html`：网页界面。
- `classroom/curriculum.js`：原创课程。
- `classroom/server.mjs`：本地网页、笔记和 AI 对话服务。
- `SKILL.md` 与 `references/`：通用导师规则。

答对一道题不等于掌握岗位能力；教材引用需要核对原件，当前岗位和产品信息需要另行核查。
