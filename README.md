# AI 转行导师 · ai-career-tutor

一个中文 AI 学习与岗位训练 Skill，面向希望理解 AI、练习实际应用或准备转行的学习者。可用于黑板课堂的导师，也可在支持 Skill 的助手中独立使用。

## 它能做什么

- 解释 AI 概念，用具体场景、类比和反例说明边界。
- 每次出一道练习，等待回答后批改，再用新场景检验迁移能力。
- 围绕 AI 产品、运营／内容策略、应用开发制定短期学习与作品任务。
- 逐题模拟面试，反馈知识、岗位判断、项目证据和表达问题。
- 根据用户自己的教材与可用检索工具，管理来源状态并引用可定位的证据。

## 使用方式

将本目录放入所用助手支持的 Skill 目录，保留 `SKILL.md` 与 `references/` 的相对位置。具体加载方式取决于使用的助手。

调用示例：

```text
使用 $ai-career-tutor。我想转 AI 产品经理，没有技术背景。
请用一个具体例子解释 RAG，再出一道题，等我回答后再批改。
```

```text
使用 $ai-career-tutor，模拟 AI 运营岗位面试。
每次只问一道题，基于我的真实回答追问。
```

## 教材与课堂

不附带教材、检索引擎、学习数据库或黑板网页。安装 Skill 不会自动创建课堂界面、连接服务或保存学习进度。独立使用无需黑板应用；连接自己的课堂时，可传入岗位目标、课程位置和带出处的教材摘录。

没有知识库也能讲解一般概念；涉及教材原意时需要可核验的原文。当前岗位、薪资和产品信息需要另行核查。它不会把演示板书当作教材，也不会把一次答对当作长期掌握。

## 文件结构

- `SKILL.md`：导师入口与教学规则。
- `references/knowledge-base.md`：通用知识库管理与检索边界。
- `references/evidence.md`：教材证据与引用规则。
- `references/interview.md`：模拟面试与反馈规则。
- `references/teaching-notes.md`：常见概念误区。

## 隐私

此分发包仅含通用规则，不包含作者的教材、聊天记录、学习档案、密钥或本地环境配置。使用者接入自己的资料时，应自行控制访问与分享范围。
